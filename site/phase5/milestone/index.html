    Phase 5 Milestone: Land the Job

    You've learned everything. Now close the deal.

    This milestone validates you're ready to interview, negotiate, and accept the right role.

    Final Readiness Checklist (30+ Items)

    GitHub Portfolio (30%)

    • [ ] 3-4 pinned projects on GitHub (polished)
    • [ ] Each project has complete README (architecture, metrics, setup)
    • [ ] Each project has Loom demo video (2 minutes or less)
    • [ ] Code has meaningful commit history (conventionalcommits)
    • [ ] CI/CD working (test badge, coverage badge)
    • [ ] All projects README link to other projects
    • [ ] Profile README complete and updated
    • [ ] No incomplete or outdated projects visible
    • [ ] Code is professional (no debug prints, no TODOs)
    • [ ] All projects have working, tested code

    Resume & LinkedIn (25%)

    • [ ] Resume one page, ATS-friendly (no fancy formatting)
    • [ ] Skills section ordered by hirability (Python → ML → Cloud)
    • [ ] Experience using CAR format (Challenge → Action → Result)
    • [ ] Projects section highlights your 3 best builds
    • [ ] All numbers quantified (not "improved", but "40% improvement")
    • [ ] LinkedIn profile 100% complete
    • [ ] LinkedIn headline has skills + differentiator + role
    • [ ] LinkedIn about section: who you are + what you build + what's next
    • [ ] Connection requests to 50+ AI engineers/recruiters
    • [ ] Cover letter template ready (customize per company)

    Interview Preparation (25%)

    • [ ] Can explain 20+ conceptual questions (RAG, fine-tuning, etc.)
    • [ ] Can design 4+ AI systems end-to-end (architecture + latency + costs)
    • [ ] Can code 10+ AI-specific challenges (similarity, caching, retrieval)
    • [ ] Done 5+ mock interviews (with peers or Pramp)
    • [ ] Can answer 5 behavioral questions with STAR format
    • [ ] Prepared 10 questions to ask interviewers
    • [ ] Know your market rate ±$10K
    • [ ] Know your non-negotiables (remote? equity? team size?)
    • [ ] Can discuss your projects in depth (know every decision)

    Job Search Strategy (20%)

    • [ ] Target list of 20+ companies (dream list + realistic list)
    • [ ] Have 2-3 personal connections at target companies (referrals > cold)
    • [ ] Application tracker (Google Sheet with status)
    • [ ] Plan to send 50-100 applications in 2 weeks
    • [ ] Customize cover letter for each application (not template)
    • [ ] Active in AI community (Twitter/Discord, visible to recruiters)
    • [ ] Network with 10+ recruiters (they have pipelines)
    • [ ] Know your timezone negotiation (remote work location impact)

    Capstone: The Portfolio Audit

    Objective: Ensure every project is portfolio-ready and interconnected.

    Project Quality Scorecard

    For each of your 8 projects, score 0-10:

    Project README Completeness Code Quality Demo Metrics Score
    RAG System 9 8 9 10 9.0
    Fine-tuning 8 9 8 9 8.5
    FastAPI 7 9 7 8 7.75
    Deployment 8 8 8 9 8.25
    MLOps 6 7 5 7 6.25
    K8s 7 8 6 8 7.25
    Avg: 7.86

    Target: Each project >8.0. If <7.0, needs more work.

    Final Project Checks (Week Before Job Search)

    For each project: - [ ] Clone repo fresh, follow setup instructions (do they work?) - [ ] Run tests (do they pass?) - [ ] Check last commit date (recent? or stale?) - [ ] Count commits (50+ is good, shows iteration) - [ ] View issues/PRs (outstanding issues would be red flag) - [ ] Count stars (good projects have 20-50+) - [ ] Have you gotten feedback? (mention in interview)

    For portfolio overall: - [ ] Can you explain each project's purpose in <30 seconds? - [ ] Can you go deep into any project for 10 minutes? - [ ] Can you discuss tradeoffs you made? - [ ] Can you show before/after of time/cost/quality?

    Self-Assessment: Job-Ready Levels

    Beginner (Not Ready Yet — Need 1-2 More Weeks)

    Indicators: - Portfolio incomplete (projects without complete READMEs) - No demo videos - Resume still generic - Mock interviews score <50% - Can't confidently answer 80% of conceptual questions

    Example: "I have projects but the READMEs are minimal and I haven't recorded demos. I get nervous in interviews."

    Action: Spend 2 more weeks polishing. Don't start job search yet; you'll waste time on rejections.

    Competent (Ready for Job Market — Go for It)

    Indicators: - 3-4 strong projects on GitHub - Complete READMEs with metrics - Loom demos visible - Resume tailored to AI roles - Mock interview score 70%+ - Can answer most conceptual questions - Know your target companies

    Example: "Portfolio is strong, resume highlights my best work with metrics. I'm prepared for interviews and know what I'm looking for. Ready to apply."

    Action: Start applying. Target 50-100 applications. Expect 5-10% callback rate.

    Hire-Ready (Stand Out — Expect Multiple Offers)

    Indicators: - Portfolio exceptional (projects have 50+ stars, shipped to production) - Metrics impressive (RAGAS scores, latency numbers, cost optimization) - Mock interview score 80%+ - Can handle all behavioral questions smoothly - Active in AI community (Twitter, Discord, visible) - Have warm connections at target companies - Know market extremely well, negotiate confidently

    Example: "Portfolio is production-grade — systems I built hold real users and metrics. I have referrals at 3 dream companies. Done system design interviews. Confident I'll get offers from tier-1 companies."

    Action: Apply strategically. You can afford to be picky. Aim for best team/equity, not highest salary.

    The Job Search Process

    Week 1: Final Prep

    Mon: Polish README for 2-3 key projects
Tue: Record Loom demos
Wed: Resume final edit, LinkedIn push
Thu: Mock interview (identify weak areas)
Fri: Update target company list

    By Friday: Fully ready to apply.

    Week 2: Apply

    Mon-Wed: Send 10-15 applications/day
(Customize cover letter for each!)

Thu-Fri: Follow up with warm connections
(LinkedIn message: "Just applied, thought you should know!")

    Target: 50-100 applications by Friday.

    Week 3: Interviews Start

    Expect: Callbacks from first 20-30 applications
First calls: Recruiter screen (30 min) → schedule deeper interviews
Pace: 2-3 interviews per day on average

    Week 4: Offers Arrive

    Company A: Offer received (counter-offer template ready)
Company B: Final interviews scheduled
Company C: Rejected (OK, move on)

Typical: 20% callback → 30% pass phone screen → 40% pass final → 50% offer

So 100 apps → 20 phone screens → 6 pass → 3 offers → pick best

    Week 5-6: Decision & Negotiation

    You likely have 2-3 offers
Negotiate each (use template from Phase 5)
Choose best fit (not just salary)
Give notice at current job

    What Not-Ready-For-Job-Market Looks Like

    ❌ Portfolio is incomplete - "I have the projects but README is just code" - "Demo video would take time, I'll skip" - Fix: Spend 1 week on READMEs and demos. Non-negotiable.

    ❌ Resume is generic - "I know machine learning and Python" - Should be: "Deployed RAG system with 0.87 RAGAS faithfulness, 45ms latency, scaled to 1000 QPS" - Fix: Rewrite each bullet with specific metrics.

    ❌ Can't discuss your own projects in detail - "I built RAG but don't remember the chunking strategy" - Fix: Go back to your code. Own it. Understand every decision.

    ❌ No way to reach you - Email hard to find, LinkedIn incomplete, GitHub profile bare - Fix: Make it easy. Bio links, consistent username everywhere.

    Job Search Red Flags

    Company Red Flags (Skip These)

    • Posting for "AI engineer" but vague requirements (don't know what they want)
    • Salary posted as "competitive" (not a number = pay less)
    • No mention of team size or tech stack (chaotic org)
    • "Move fast and break things" culture (burnout city)
    • VCs, not product (research jobs, not production)
    • Required on-site for "company culture" (inflexible, probably bad)

    Interview Red Flags

    • No portfolio discussion (they don't care about your work)
    • All questions from LeetCode (no system design = junior company)
    • Asked personal questions (age, marital status, etc. = illegal + immature)
    • Vague about the actual role (bait and switch)
    • No technical depth from interviewers (they can't evaluate you fairly)

    Expected Outcomes

    Timeline (Realistic)

    Day 1: Decide to start job search
Days 1-3: Final portfolio prep
Days 4-11: 100 applications sent
Days 12-17: First callbacks
Days 18-31: Interview loop (sometimes multiple)
Days 32-38: Offer negotiations
Days 39-45: Accepted role, give notice
Days 46-60: Transition period
Day 60+: First day at new job

    Total: 2-3 months for full cycle.

    Callback Rates (Our Experience)

    100 cold applications → 5-10 callbacks (5-10%)
With referrals: 50 applications → 10-15 callbacks (20-30%)

Callbacks that pass phone screen: 30-40%
Phone screens that pass final loop: 40-50%
Final loops that extend offers: 50-70%

So 100 cold apps → 5 callbacks → 2 phone passes → 1 final → 0.5 offers
With 50 referrals → 15 callbacks → 6 phone passes → 3 finals → 2 offers

    Key: Referrals are 4x better than cold applications.

    First Job in AI Role: What's Normal

    Month 1: Onboarding

    • Meet team, understand codebase
    • You'll feel dumb ("How does this work?") ← normal
    • Pair with senior engineer
    • First project: small, self-contained

    Month 3: Ramping

    • Completing projects without help
    • Understanding team dynamics
    • Building relationships
    • Prove yourself reliable

    Month 6: Contributing

    • Leading small projects
    • Mentoring others (even if just 1 person)
    • Opinions are respected
    • Consider asking for raise (often not automatic)

    Month 12: Strategic

    • Clear growth path in your mind
    • Company's evaluation of you is clear (good/bad/neutral)
    • Decide: stay and push for promotion, or job search?
