    Phase 5: Portfolio & Jobs

    You've built AI systems. You've deployed them. You've operated them.

    Now, show the world.

    This phase teaches you to land the job:

    1. GitHub Portfolio — what projects to feature and how
    2. Resume & LinkedIn — what makes AI engineers compelling
    3. System Design Interviews — thinking like a senior engineer
    4. Mock Interviews — practice the hard questions
    5. Salary Negotiation — understand what you're worth

    Why Portfolio Matters More Than You Think

    Recruiters spend 6 seconds glancing at your resume.

    But if you have a live demo? They spend 6 minutes.

    A GitHub project with 500 stars? They reconsider your seniority.

    The harsh truth: a great portfolio can get you hired even without a degree. A bad portfolio can't get you hired even with one.

    Why?

    • Resume is claims ("I built RAG systems")
    • GitHub is proof (they can see, run, test your code)
    • Live demo is credibility (the system actually works)

    Recruiters trust proof more than claims.

    What This Phase Covers

    Week 1: GitHub & Portfolio - Which 8 projects to feature (from Phases 1-4) - How to make each project portfolio-worthy - Recording demo videos - GitHub profile optimization

    Week 2: Resume & LinkedIn - Resume structure that passes ATS (Applicant Tracking System) - LinkedIn profile that gets recruiter attention - Keywords that matter for AI roles - Cover letter strategy

    Week 3: System Design & Interviews - How to think through production AI system design - Full walkthroughs of 4 real system design problems - Interview frameworks and what they're testing

    Week 4: Mock Practice & Negotiation - 20 conceptual questions with answers - 10 system design scenarios - 10 coding challenges (AI-specific) - Behavioral interview patterns - Salary expectations by level and location - How to negotiate without burning bridges

    The 3 Things That Get AI Engineers Interviews

    1. GitHub Portfolio — code they can evaluate
    2. 3-8 polished projects
    3. Complete documentation
    4. Working demos

    5. Clean commit history

    6. Live Demo — they see it working

    7. 2-minute Loom video
    8. Short, punchy (problem → solution → result)

    9. Shows the value, not slides

    10. Clear Narrative — why you built what you built

    11. "I noticed problem X"
    12. "I built Y to solve it"
    13. "Achieved result Z"
    14. Show intentionality, not random projects

    Most engineers have nothing. You'll have all 3.

    Your Competitive Advantage

    After this roadmap, you'll have:

    ✅ Technical Depth - Built AI systems (Phases 1-3) - Deployed at scale (Phase 4) - 20+ weeks of focused learning

    ✅ Portfolio - 8 GitHub projects - Demo videos - Production-ready code - Real evaluation metrics

    ✅ Clear Communication - Can explain any technical decision - Know tradeoffs (cost vs accuracy, latency vs quality) - Think like senior engineer in interviews

    ✅ Interview Prep - Mock interviews completed - System design frameworks solid - Behavioral stories prepared

    This positions you far ahead of bootcamp graduates or self-taught engineers. Seriously.

    Timeline

    3-4 weeks to prepare for job search: - Week 1: Polish GitHub + portfolio - Week 2: Resume + LinkedIn optimization - Week 3: System design + mock interviews - Week 4: Apply to jobs + negotiate

    By week 5, you'll have interviews lined up.

    Phase 5 Topics

    1. GitHub Portfolio → — What projects, how to present
    2. Resume & LinkedIn → — Getting recruiter attention
    3. System Design Interviews → — Thinking through complex problems
    4. Mock Interviews → — Practice questions with answers
    5. Salary Negotiation → — Understanding market rates
    6. Milestone → — Final portfolio audit

    How to Use This Phase

    Option 1: Do it Sequentially 1. Polish portfolio (week 1) 2. Update resume/LinkedIn (week 2) 3. Study system design (week 3) 4. Do mock interviews (week 4) 5. Apply to jobs (ongoing)

    Option 2: Interview-Focused If you have an interview coming: 1. Skim all sections (1 hour) 2. Deep dive system design (relevant problem type) 3. Practice mock questions (2 hours) 4. Review salary expectations (30 min)

    Option 3: Portfolio-First If not yet job-ready: 1. Spend extra time on GitHub polish 2. Record every demo video 3. Get portfolio feedback from peers/mentors 4. Then start interviewing

    Brutal Honesty: What Actually Works

    ✅ Works: - Personal projects with real impact (hard to fake) - Loom demos (AI recruiters actually watch them) - GitHub stars/contributions (signal of quality) - Specific metrics ("improved latency by 40%") - Referrals (best way to get interviews) - Being in the AI community (Twitter, Discord, conferences)

    ❌ Doesn't Work: - "I'm passionate about AI" (says nothing) - Fake projects (they'll ask you questions in interview) - Inflating job titles (they'll check references) - Resume buzzwords with no depth (HiringManager asks: "Explain RAG") - Applying blind (worse odds than referral) - Applying to every job without customization (signals you're not serious)

    Market Reality (2025)

    AI engineer demand is insane: - Salary: $150K - $300K+ (depending on level, location) - Job openings: 100x more than qualified candidates - Remote options: highly flexible - Signing bonuses: common ($50K-$150K)

    But: - Companies are picky (want proven track record) - Interview bars are high (system design, coding, behavioral) - Equity matters (some companies are better positioned) - Team quality varies wildly

    Your goal: Find the right company with good team, negotiate hard, learn fast.
